# Offline data

All runtime data is shipped in the app bundle. First use copies the 9 MB SQLite
catalog into application documents; the JSON notable-object sidecar remains in
the bundle and is loaded locally. No catalog update service exists.

## Bundled sources

| Content | Upstream source and pin | Local use | License |
|---|---|---|---|
| Stars | HYG Database v4.1, commit `c7f7f883fe678cc7680169a50ccd7dcc49b060ce` | Stars to visual magnitude 6.5 plus stars referenced by constellation figures; names, aliases, J2000 coordinates, proper motion, available magnitude/distance | CC BY-SA 4.0 |
| Deep-sky objects | OpenNGC `v20260501`, commit `36cb178a0f69dba8bfc03a99c10512831edf1c6b` | Valid object positions, types, names/aliases, catalog designations, available magnitude | CC BY-SA 4.0 |
| Constellation figures | Stellarium modern sky culture, snapshot `8184399cd363a5fea10e5fb7703a4687752812ae` | The 88 names/abbreviations and star-line patterns only; no artwork | CC BY-SA 4.0 for text/data |
| Notable targets | Selected SIMBAD records queried 2026-10-16 | Eight black-hole source/system positions and the Milky Way Galactic Center marker, stored separately in `assets/catalogs/notable_objects.json` | ODbL 1.0 |
| Solar System models | Astronomy Engine 2.1.19, commit `61dc07020aaa6885d2c7f688a4d82beaf6edb9ef` | C implementation compiled for Android/iOS and called with Dart FFI | MIT |

The local SQLite file is generated by `tooling/build_catalog.py`. It contains
22,220 catalog objects, 88 constellations, and 695 stick-figure line segments.
The notable targets are kept in a separate ODbL JSON file rather than merged
into the CC BY-SA SQLite catalog.

SIMBAD is operated by CDS, Strasbourg, France. Its service describes itself as
available under ODbL and requests citation of Wenger et al. 2000, A&AS 143, 9.
The selected records use radio, optical, infrared, or X-ray positions of the
source/counterpart. A black-hole marker does not represent a resolved event
horizon. The Milky Way record points to Sagittarius A* to represent the
direction of the Galactic Center; the extended Milky Way band is computed from
the IAU Galactic coordinate frame.

## Attribution and redistribution

The bundled `assets/licenses/` folder contains the CC BY-SA, ODbL, HYG,
OpenNGC code, and Astronomy Engine notices. It also includes
`THIRD_PARTY_DATA.md` with source pins, transformations, and attribution.
The app's Settings page displays the source names and licenses. The SIMBAD
notable-target JSON is an ODbL database subset and must remain available with
its license and attribution if redistributed. Consult the individual source
licenses before modifying or republishing the catalog assets.

## Offline guarantees

- Database asset and notable JSON are read from the application bundle.
- SQLite searches, object selection, favorites, and ephemeris calculations
  make no network requests.
- The optimized release APK was inspected and contains no `INTERNET` permission.
  Flutter's debug/profile variants add it for the VM service; no application
  feature uses it.
- GNSS may work with no internet when satellites can be acquired. The app
  does not promise an offline network-derived location. Manual and saved
  coordinates work without GPS.
- Device true-north estimates can depend on OS location/magnetic models; the
  app identifies magnetic north when true north is unavailable.
